## What I'm building

**[TreasuredWord](https://github.com/Daniel-Pino-2000/TreasuredWord)** is an offline-first Android Bible app, now at v1.7 in Google Play closed testing and available in 10 languages. It has account sync through a Ktor + PostgreSQL backend I built and deployed, a home-screen widget, verse images, and an AI "Bible Helper" running on Cloudflare Workers AI. It's backed by 500+ unit tests and CI.<br>
🚧 *Next: streaming AI answers, semantic verse search with pgvector, and the public Play Store launch.*

**[CodeHired](https://github.com/Daniel-Pino-2000/CodeHired)** is a US tech-jobs aggregator with an Express 5 + TypeScript API and a React 19 web app.<br>
🚧 *Next: ingesting jobs from Greenhouse, Lever, Ashby, Adzuna, USAJobs and JSearch on a schedule, plus full-text search, accounts and application tracking, deployed for $0 on Vercel + Turso.*
